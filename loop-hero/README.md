# 循环勇者 · Loop Hero 网页复刻

一个纯前端、零依赖、无外部图片素材的《循环勇者》(Loop Hero) 同人复刻。
英雄沿着环线自动行走、自动战斗；你把卡牌铺成地形，地形强化你，也招来敌人；篝火、装备、天赋和巫妖首领构成一次完整的远征。

> 非官方同人学习项目，与 Four Quarters / Devolver Digital 无关。项目不包含任何原作美术或音频；中文字体使用 OFL 许可的 Noto Sans SC。游戏名称、卡牌与设定版权归原作者，请勿商用或再分发。

## 运行

需要 Node.js（本机为 v24，任意近年版本均可）：

```powershell
cd loop-hero
node server.mjs
# 或 npm start
```

然后打开 <http://127.0.0.1:5173>。

也可以双击 `start.ps1`：它会启动一个本地服务并打开浏览器。

> 必须通过 `http://` 打开。项目使用 ES Modules，直接双击 `index.html`（`file://`）会被浏览器拦下。

## 操作

| 操作 | 说明 |
| --- | --- |
| 点击手牌 / 数字键 `1`–`7` | 选中卡牌；再点一次取消 |
| 点击地图空格 | 放置卡牌（绿色可放，红色不可放） |
| 鼠标悬停 | 查看卡牌、地形、装备、属性、敌人与建筑的具体效果 |
| 营地牌组 | 左键加一张；满编时左键点已选牌减一张；右键减一张；至少 10、最多 30 |
| 右键 | 手牌上右键弃牌；地图空白处右键取消选牌 |
| `Q` | 喝药水（回复 45% 生命，每次远征 1 瓶） |
| 空格 | 暂停 / 继续 |
| `S` | 切换 1× / 2× / 3× 速度 |
| 撤退按钮 | 带着本局资源回营地 |

## 已实现

**界面**
- 现代暗色玻璃风格（非原版像素 UI）：圆角面板、柔和阴影、金色点缀、无扫描线
- 英雄 / 怪物 / 地形全部由 Canvas 代码绘制，不使用游戏素材
- 中文字体为 OFL 许可的 Noto Sans SC（`assets/fonts/OFL.txt`）

**远征**
- 三职业：战士（反击）、盗贼（双持 / 连击 / 战利品）、死灵法师（召唤骷髅、法杖强化）
- 76 格闭合环线，英雄自动行走，遇敌自动开战
- 野地牌可铺在环线内外的空地上，路边牌只能贴道路；麦田需邻村庄、血魔树林需邻森林
- 实时战斗：攻速、暴击、吸血、闪避、防御减伤、每秒回复；第 4 圈起同格最多 3 个敌人
- 15 种敌人拥有独立能力：分裂、中毒、窃取装备、复生、远程先手、硬化、再生、嗜血、沙幕、惑歌、余烬、治疗光环
- 敌人随圈数成长；精英怪、Boss 召唤、半血狂暴
- 4 章 + 无尽回廊：巫妖 / 女祭司 / 猎手 / 终焉，每章不同首领机制
- 装备掉落（武器 / 副手 / 法杖 / 护甲 / 饰品 / 戒指，普通 / 稀有 / 史诗）；拾取面板三选一，支持 12 格背包与自动装备开关
- 词条池：攻击、防御、生命、攻速、暴击、暴伤、吸血、回复、闪避、掉落、经验、反击、减伤
- 升级三选一天赋（19 种，按职业过滤）

**卡牌与地形**（55 张卡组牌 + 2 张场景牌）
- 野地牌：岩石、山脉、山峰、森林、灌木丛、草地、茂密草原、河流、桥、沙丘、沙漠、绿洲、血魔树林、麦田、焦土森林、饥饿树林、茂草原、郊区、小镇、芦苇、时空水晶、旱灌木、荒地
- 路边牌：村庄、伯爵领地、女巫之屋、墓园、蜘蛛茧、小树林、吸血鬼别墅、山贼营地、哥布林营地、哥布林瞭望台、遗迹、沼泽、铁匠炉、军械库、宝库、瞭望塔、前哨站、塔庙、风暴神殿、战场、被洗劫的村庄、一座村庄？、沉船、血魔路径、巫妖宫殿、灯塔、图书室、废弃图书室、路灯、零之界标、追忆迷宫、异次元裂缝、时空灯塔、祖先墓穴
- 地形组合：岩石 → 山脉；森林 → 灌木丛；草地 → 茂密草原；沙丘 → 沙漠；另有 12 条跨卡牌联动（村庄+吸血鬼别墅/麦田、墓园+村庄/墓园、沙丘/沙漠+河流、战场+血魔树林、森林+焦土森林、沼泽+河流、蜘蛛茧+森林、哥布林营地+岩石、遗迹+遗迹）
- 图鉴：营地内打开，记录已见卡牌、隐藏组合、敌人、首领与建筑；未发现的显示为「？？？」并给出解锁/触发提示
- 特殊牌「遗忘皆空」：销毁任意已放置地形
- 地形机制：生命、攻击、攻速、回复、吸血、闪避、经验、移速、掉落品质、魂晶、敌人减伤、敌人上限、药水补给、资源补给

**营地**
- 23 种建筑：营火、训练场、田园、墓园、猎人小屋、铁匠铺、瞭望塔、强盗要塞、盗贼公会、地下墓穴、图书馆、军械库、灯塔、情报所、客栈、医师的小屋、出色的铁炉、补给站、伐木工、森林、熔炼炉、学院、炼金术士帐篷
- 手动组牌：从已解锁卡池里选 10–30 张，同名最多 2 份；也可一键恢复自动牌组
- 资源：木材 / 石料 / 魂晶 / 稳定金属 / 记忆碎片 / 古籍
- 建筑分基础 / 进阶 / 高阶三档，高阶有前置校验；解锁新卡牌、职业与永久强化
- 死亡 / 撤退 / 通关都会带回资源并生成战报（击杀、圈数、铺牌、伤害、入账清单）；进度存 `localStorage`

## 与原作的差异

- 地形组合 4 组转化 + 12 条联动，部分原作组合未逐条对齐
- 追忆迷宫 / 桥按原作保持无效果；地形美术与音效未做
- 战斗最多 2 个敌人同格，原作可更多
- 装备自动穿戴更强的，没有背包与手动比较界面
- 建筑升级分支与前置条件仍是简化版
- 所有画面由 Canvas 代码绘制，不使用游戏贴图或音频；字体为 OFL 许可

## 文件结构

```
index.html            页面骨架与 HUD
css/style.css         基础样式
css/theme-modern.css  现代暗色主题
assets/fonts/         Noto Sans SC（OFL）与许可证
server.mjs            零依赖静态服务器
start.ps1             一键启动
js/main.js            入口与主循环
js/game.js            编排层：移动 / 铺牌 / 输入 / 结算（战斗等逻辑已下沉）
js/core/              常量、随机数
js/data/              卡牌、敌人、天赋、建筑数据
js/world/             环线地图、英雄属性
js/systems/           战斗、刷怪、手牌、经济、棋盘、地形效果、特效、坐标、掉落、营地、存档
js/ui/                HUD、全屏界面、输入、悬浮说明
js/render/scene.js    Canvas 绘制（地形缓存 + 动态层）
tools/cdp.mjs         无头浏览器调试脚本
tools/simulate.mjs    批量平衡模拟（见下）
tests/                逻辑、集成模拟、渲染冒烟测试
```

## 测试

```powershell
node tests/logic.test.mjs    # 地图 / 铺牌 / 属性 / 掉落 / 营地
node tests/sim.test.mjs      # 用最小 DOM 桩驱动真实 Game 循环跑完一局 + 平衡回归
node tests/render.test.mjs   # 假 Canvas 上下文跑渲染，抓运行时错误
```

`sim.test.mjs` 会自动铺牌、选天赋，通常能在第 8 圈打完巫妖，可用来观察数值是否失控；末尾会跑 4 组 × 10 局的平衡回归。

## 平衡模拟

```powershell
node tools/simulate.mjs --n 40 --chapter 3 --class rogue   # 单组合
node tools/simulate.mjs --all --n 40 --out docs/balance.md # 3 职业 11 组合全矩阵，写出基线表
```

固定 seed（可复现），输出胜率 / 通关中位圈 / 死亡圈分位 / 每圈击杀与承伤 / 资源收入 / Boss 战时长。
当前基线见 `docs/balance.md`，已知的平衡问题与待校准项见 `docs/ROADMAP.md` 附录 B。
