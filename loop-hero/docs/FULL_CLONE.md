# 「完全复刻」对照表与路线

最后更新：2026-10-29（第 2 轮）

## 先说边界

1. **美术与音频**：本项目不打包任何游戏贴图或音频。英雄、怪物、地形全部由 Canvas 代码绘制；中文字体使用 OFL 许可的 Noto Sans SC。
2. **精确数值**：`variables.ini` 给出了一部分公式常量，但完整的伤害、掉落与 AI 权重仍在 `data.win` 里，无法逐项还原。当前数值按公开资料 + 变量文件 + 模拟调平逼近。

目标是把**机制与内容做全**：职业、卡牌、组合、建筑、章节、首领、模式都不缺。

## 阶段

### P1 三职业（完成）
- 职业数据与基础属性分离：`js/data/classes.js`
- 职业选择 UI、解锁建筑（盗贼公会 / 地下墓穴）
- 战士：受击 20% 反击
- 盗贼：双持、20% 连击、击杀战利品、无护甲
- 死灵法师：召唤骷髅（2–3 只）、骷髅承担 65% 攻击、法杖强化
- 装备栏与掉落按职业槽位动态生成

### P2 全卡牌（完成）
- 卡池对照本机文本扩到 55 张卡组牌 + 2 张场景牌，原版 60 个卡牌名称 100% 覆盖
- 「遗忘皆空」：可销毁任意已放置地形
- 特殊机制：图书室换牌/20 张后倒塌、零之界标按距离强弱、时空水晶相邻翻倍、祖先墓穴一次复活、军械库额外装备栏、手牌右键弃置、村庄/伯爵任务、战场宝箱、异次元裂缝精英、铁匠炉熔装备换减伤
- 新机制：攻击、经验、移速、魂晶掉落、敌人减伤、敌人上限、药水补给、资源补给、祖先墓穴加血上限
- 新敌人 15 种：灵书、尸鬼、稻草人、木制勇士、海妖、魔血块、哥布林弓箭手、沙漠之灵、焦火蠕虫、鱼人、鹰身女妖、石像鬼等

### P4 章节与模式（完成）
